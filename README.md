# Portfolio Frontend

This repository contains the frontend of my personal portfolio website, will be build with **Vue.js** and **Vite**.  
It aims to showcase my projects, skills, and professional journey — while integrating live **observability metrics** powered by **OpenTelemetry**.

## Technologies
- Vue.js 3
- Three.js
- HTML / CSS / JavaScript  
- Vite  
- OpenTelemetry (frontend tracing)

## Goals
- Strengthen my frontend development skills  
- Learn modern Vue.js patterns  
- Integrate telemetry and data visualization
